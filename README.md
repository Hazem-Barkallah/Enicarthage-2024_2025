ENICarthage Student Success Predictor is a complete educational tool combining machine learning and modern web development. Developed with the MERN stack (MongoDB, Express.js, React, Node.js) and a FastAPI service for serving predictions, this app allows engineering students to input their first-semester grades and instantly receive AI-generated success predictions. With interactive UI components, data visualization, and API-driven architecture, the project highlights real-world integration of ML models in web applications, offering valuable experience in both backend and frontend systems. Designed for scalability and learning, it demonstrates how intelligent tools can enhance academic tracking and support.
